# 주식 보드

국내 주식(코스피·코스닥) 시세를 간편하게 보는 웹앱입니다. PC와 휴대폰 브라우저에서 모두 쓸 수 있습니다.

## 기능
- 코스피, 코스닥, 코스피200 지수
- 관심 종목의 현재가, 등락, 등락률 (장중 약 7초마다 자동 갱신)
- 종목명·코드 검색으로 관심 종목 추가 (브라우저에 저장됨)
- 종목을 누르면 상세 화면: 1일(분봉), 3개월, 1년 차트와 시가·고가·저가·거래량 표시
- 한국식 색상(상승 빨강, 하락 파랑), 다크 모드 지원

## 실행 방법
Node.js 18 이상이 필요하며, 설치할 패키지는 없습니다.

```bash
npm start
# 브라우저에서 http://localhost:3000 접속
```

포트를 바꾸려면 `PORT=8080 npm start` 처럼 실행하세요.

## 구조
```
server.js            정적 파일 제공 + /api/* 시세 중계 (짧은 캐시 포함)
providers/naver.js   시세 제공자 (네이버 증권)
public/              화면 (HTML/CSS/JS)
```

| API | 설명 |
|---|---|
| `GET /api/quotes?codes=005930,000660` | 종목 현재가 |
| `GET /api/indices` | 코스피·코스닥·코스피200 |
| `GET /api/search?q=삼성` | 종목 검색 |
| `GET /api/chart/005930?range=1d\|3m\|1y` | 차트 데이터 |

## 데이터 출처 관련 주의
- 시세는 **네이버 증권의 비공식 엔드포인트**에서 가져옵니다. 증권사 계좌 없이 쓸 수 있지만, 공식 API가 아니어서 예고 없이 바뀌거나 막힐 수 있습니다.
- **개인 참고용**으로만 사용하세요. 시세를 다른 사람에게 서비스하거나 재배포하면 이용약관 및 거래소 시세 라이선스 문제가 생길 수 있습니다.
- 나중에 증권사 계좌를 만들면 `providers/kis.js` 처럼 같은 함수(`getQuotes`, `getIndices`, `search`, `getChart`)를 가진 파일을 만들고 `server.js`의 import만 바꾸면 됩니다. 한국투자증권 KIS Developers API는 웹소켓 실시간 시세를 공식적으로 제공합니다.
